> 一款零依赖、单文件的网页扫雷游戏：**10 关递进挑战**、**三星评定**，以及每关 3 次的**撤回**与**提示**。

经典扫雷的规则，加上一点闯关游戏的成就感。全部代码都在一个 `index.html` 里，不需要安装、不需要构建，双击即玩。

## ✨ 特性

- 🎯 **10 个递进关卡**：从 8×8 / 8 雷的新手入门，一路打到 22×22 / 99 雷的终极魔王
- ⭐ **三星评定**：按通关用时评 1–3 星，只记录每关的最好成绩，主页汇总总星数
- 🛡️ **首点安全**：第一次点击后才布雷，并保证点击位置周围 3×3 无雷，开局不靠运气
- ↩️ **撤回**：每关 3 次，撤销上一步揭开或插旗操作
- 💡 **提示**：每关 3 次，高亮一个尚未揭开的安全格
- ⚡ **和弦操作**：旗子插对后，点数字一键揭开周围剩余格子
- 💾 **自动存档**：关卡解锁与星级保存在 `localStorage`，关闭页面也不丢进度
- 🔊 **合成音效**：用 Web Audio API 实时合成，无需任何音频文件，可随时静音
- 🎨 **视觉特效**：动态渐变背景、漂浮粒子、烟花庆祝、踩雷震屏、发光数字
- 📦 **零依赖**：原生 HTML / CSS / JavaScript，无框架、无打包、无网络请求

## 🎮 玩法与操作

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 揭开格子 |
| 右键点击 | 插上 / 移除旗子 |
| 点击已揭开的数字 | 当周围旗子数等于该数字时，揭开其余相邻格（和弦） |
| 点击笑脸 🙂 | 重新开始当前关卡 |
| 撤回 / 提示 | 使用对应道具 |

规则很简单：

- 数字表示**周围 8 格**中地雷的数量；
- 揭开所有非地雷格子即通关，踩到地雷则失败；
- 第一次点击一定安全，可以放心开局。

### ⭐ 星级评定

| 星级 | 条件 |
| --- | --- |
| ⭐⭐⭐ | 用时 ≤ 该关三星目标 |
| ⭐⭐ | 用时 ≤ 该关二星目标 |
| ⭐ | 完成关卡即可获得 |

每关只保留历史最高星级；通关后会解锁下一关，主页会显示已解锁关卡数与累计星数。

### 🎒 道具

| 道具 | 数量 | 效果 |
| --- | --- | --- |
| ↩️ 撤回 | 每关 3 次 | 回到上一步操作前的棋盘状态（最多回溯 10 步） |
| 💡 提示 | 每关 3 次 | 随机高亮一个未揭开的安全格，只提示、不代揭 |

## 🚀 快速开始

### 方式一：直接打开

下载或克隆仓库后，双击 `index.html` 即可在浏览器中游玩。

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
```

### 方式二：本地静态服务器

如果想用 `http://localhost` 访问（例如测试存档或部署行为）：

```bash
# Python 3
python -m http.server 8000
```

或使用 Node.js：

```bash
npx serve .
```

然后打开 <http://localhost:8000>。

> 项目没有 `npm install`、没有构建步骤，`index.html` 就是全部。

## 🌐 部署到 GitHub Pages

因为入口就是根目录的 `index.html`，部署只需要几步：

1. 把项目推送到 GitHub 仓库；

5. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

无需修改任何路径或配置。

## 🧠 实现要点

- **延迟布雷**：首次点击后才随机生成地雷，并排除点击位置周围 3×3，既保证首点安全，也让开局有可展开空间。
- **洪水填充**：揭开数字为 0 的格子时，递归揭开相邻格，形成经典的成片展开效果。
- **状态快照**：撤回通过 `history` 栈保存 `revealed`、`flagged`、剩余雷数和计时的深拷贝，回退时整体恢复。
- **胜负判定**：已揭开格数等于 `rows × cols − mines` 即通关；踩雷立即失败，并展示全部地雷与插错的旗子。
- **存档**：`localStorage` 保存 `{ unlockedLevel, levelStars }`，音效开关单独保存。
- **音效**：用 `OscillatorNode` + `GainNode` 实时合成点击、插旗、爆炸、胜利等音色，无外部资源。
- **渲染**：CSS Grid 布局，每个格子对应一个 `div.cell`，通过 class 切换揭开、插旗、数字等状态。

## ⚙️ 自定义

### 调整关卡

在 `index.html` 中找到 `LEVELS` 数组，按同样的结构增删关卡即可：

```js
const LEVELS = [
  { rows: 8, cols: 8, mines: 8, name: "新手入门", threeStar: 30, twoStar: 60 },
  // ...
];
```

| 字段 | 含义 |
| --- | --- |
| `rows` / `cols` | 棋盘行数与列数 |
| `mines` | 地雷数量 |
| `name` | 关卡名称，显示在顶部信息栏 |
| `threeStar` / `twoStar` | 获得三星 / 二星的时间上限（秒） |

### 调整道具数量

```js
const MAX_UNDO = 3;
const MAX_HINT = 3;
```

### 调整外观

配色、圆角、动画都写在 `index.html` 顶部的 `<style>` 中。背景渐变在 `.bg-animated`，数字颜色在 `.num-1` 到 `.num-8`。

## ❓ 常见问题

**进度保存在哪里？**

浏览器的 `localStorage` 中，键名为 `minesweeper_progress`；音效开关的键名为 `minesweeper_audio`。换浏览器或换设备不会同步。

**怎么重置全部进度？**

在浏览器开发者工具的 Console 中执行：

```js
localStorage.removeItem('minesweeper_progress');
location.reload();
```

**手机上能玩吗？**

可以点击揭开格子，但右键插旗在触屏上不太方便，部分浏览器支持长按触发。建议在桌面端体验完整操作。

**为什么没有声音？**

浏览器要求用户交互后才允许播放音频。开始游戏或点击页面后即可正常发声；也可以在开始页用「🔊 音效」按钮切换静音。

**为什么第一下从来不会踩雷？**

地雷是在第一次点击之后才生成的，并且会避开点击格周围的 3×3 区域。这是有意设计，不是 bug。
